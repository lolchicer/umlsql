# правила именования свойств классов

## определения

класс – тип объекта

свойство – свойство сущности

## именование

### тип

свойство называется типом – type – в случае, если класс представляет собой тип переменных, от которых зависит работа определённой функции.

#### аргумент

для аргумента типом является функция.

### объект

свойство называется объектом – object – в случае, если класс представляет собой представление какого-либо типа работы, объектом работы которого является свойство.

допустимо называть свойство именем типа объекта.

#### аргумент

для аргумента объектом влияния является функция.

#### интерфейс

для интерфейса объектом представления является функция.

#### метод

для метода объектом представления является аргумент.

#### возвращающее свойство

для возвращаюего свойства объектом представления является метод.

#### устанавливающее свойство

для устанавливающего свойства объектом представления является метод.
